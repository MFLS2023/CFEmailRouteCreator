# 📬 CF Email Route Creator & Email Extractor 工具集

> 一组基于浏览器控制台的自动化脚本，专为 Cloudflare Email Routing ( CF 域名邮箱）页面设计，支持批量创建转发邮箱、提取唯一邮箱地址。无需安装插件，一键粘贴即用！

---

## 🧩 项目结构

| 📁 文件夹名               | 功能描述 |
|-------------------------|----------|
| `CFEmailRouteCreator1` | ✅ 默认选择 **下拉框第一个** 转发地址并创建邮箱 |
| `CFEmailRouteCreator2` | ✅ 默认选择 **下拉框第二个** 作为转发目标 |
| `CFEmailRouteCreator3` | 📝 允许用户手动输入目标地址（需存在于下拉选项中） |
| `SoloEmailExtractor`   | 🧼 将一段文本中的邮箱提取出来，并完全剔除重复项，仅保留唯一邮箱 |

---

## 💻 使用方式

### 通用步骤：

1. 打开 Cloudflare 的邮箱路由管理页面；
2. 按下 `F12` 打开浏览器开发者控制台；
3. 选择合适的脚本粘贴进去并回车执行；
4. 根据提示输入要创建的邮箱数量 / 后缀 / 自定义地址（如适用）；
5. 等待脚本运行结束即可自动输出结果。

---

## 🛠 脚本功能详解

### 🔹 `CFEmailRouteCreator1`

- 默认选择下拉框中的第一个目标地址；
- 自动批量创建随机前缀邮箱（3~9个字母 + 3~5个数字）；
- 将完整邮箱地址显示在控制台 & 页面右上角供复制；
- 支持用户指定邮箱后缀；
- 提供失败重试机制。

### 🔹 `CFEmailRouteCreator2`

- 逻辑与 Creator1 相同，但默认选择下拉列表的 **第二个转发地址（index = 1）**；
- 适合默认目标为第二项的用户；
- 若需修改选择顺序，可将 `selectOption(1)` 改为 `selectOption(n)` 自定义。

### 🔹 `CFEmailRouteCreator3`

- 与前两者相比，**新增了手动输入目标地址**的弹窗；
- 用户可输入地址关键词，系统会在下拉候选项中自动匹配并选择；
- 若留空，则回退为默认选择第一个。

### 🔹 `SoloEmailExtractor`

- 打开页面并运行脚本后，会弹出遮罩层和输入框；
- 粘贴任意包含邮箱地址的文本（如日志、评论、导出数据）；
- 自动提取所有邮箱，仅保留出现一次的邮箱；
- 支持一键复制结果。

## 📌 注意事项

- 所有脚本均为一次性控制台工具，不需刷新页面即可反复执行；
- 如遇页面结构变动导致脚本失效，可修改选择器或反馈 issue；
- 请在目标地址已在下拉列表中的前提下使用 `CFEmailRouteCreator1`（推荐） 或 `CFEmailRouteCreator3`。
